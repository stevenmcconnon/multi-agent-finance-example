# Diagrams

Three kinds live in this repository.

**Hand-written Scalable Vector Graphics (SVG)** (`stack.svg`, `aws.svg`,
`multi-agent-rag-architecture.svg`). They are plain text with a fixed `viewBox`, `system-ui` fonts, no
external assets, and colours chosen to read on both the light and dark GitHub themes. Edit them in a text
editor; the layout uses `<rect>`, `<text>`, paths, and arrowhead markers. Check a change by opening the file
in a browser at 100 % zoom: every label must be readable without zooming.

**Annotated product image** (`multi-agent-rag-turn-annotated.png`), the README hero. It is generated by
`make_hero.mjs` in this folder from a live run of the local stack. It identifies the question, authorization
gate, authorized retrieval, and write/verify stages for a first-time README reader. If the product timeline
changes, run the script again rather than editing the old interface into a new state.

**Screenshots** (`../screenshots/`), sixteen PNGs of the current user interface, referenced by
[`../DEMO.md`](../DEMO.md): `01-signin.png`, `02-alice-chat.png`, `03-alice-documents.png`, `04-replay.png`,
`05-bob-chat.png`, `06-bob-documents.png`, `07-carol-hitl.png`, `08-carol-approved.png`,
`09-mobile-chat.png`, `10-persona-compare.png`, `11-examples.png`, `12-agent-team.png`,
`13-revenue-facts.png`, `14-net-income-calculator.png`, `15-alice-ticket-refused.png`,
`16-director-8k-bob.png`. Re-shoot the set when the interface changes.

`stack.svg` is seven rows (L7 down to L1), each with the layer name, its folder, and two cells: "Local demo
(what `make up` runs)" and "Cloud mode (Terraform, not applied)", a few technology names per cell.
To regenerate it: edit the text, keeping only technologies that `grep` finds in `pyproject.toml`,
`apps/web/package.json`, `docker-compose.yml` or `infra/terraform` (no library that is merely planned), then
keep it in step with the README's "System design at a glance" list and the layer headings in `../ARCHITECTURE.md`. Row bands are mid-dark fills with white text; cells are
`#f8fafc` with `#111827` text, so both read on either GitHub theme. `aws.svg` names the Terraform modules' resources; keep it in step with
`infra/terraform/modules`. Neither carries a number that was not measured here.

`multi-agent-rag-architecture.svg` is the portfolio-level system view. It must keep three visual classes
distinct: teal for deterministic controls, purple for model reasoning, and amber for a human decision. Its
agent names and sequence must match `services/finance_agents/agent/graph.py` (`_graph()`) and `agent/team.py`; when a node or edge changes there, change the diagram in the same commit. Its
control plane must stay aligned with `docs/GUARDRAILS.md`.
