# Guardrails

Every guardrail in the system, existing and new, in one table. "Local demo" is the docker compose stack (`HR_MODE=local`, `HR_MODEL_BACKEND=fake`); "cloud" is the Terraform deployment in `infra/terraform`. Paths are relative to `services/finance_agents/` unless they start with `infra/` or `db/`; tests live in `tests/`.

Acronyms: ACL = access control list; PII = personally identifiable information; SSN = Social Security number; JWT = JSON Web Token; SQL = Structured Query Language; HITL = human in the loop; SSE = server-sent events; AVP = Amazon Verified Permissions.

## In production / in this demo

In production: Bedrock Guardrails run on every model call and both ends of the turn, PII detection is a managed classifier, and the rate limit sits behind the load balancer's own limits.
In this demo: the compose stack has no AWS, so only the regex checks and the Redis counter run, because the fake gateway and offline tests are the whole local story.

## Honest limits

- Pattern lists are not classifiers. The injection list catches the phrasings it names and no paraphrase; the PII patterns catch the shapes they name (US phone formats, `nnn-nn-nnnn` SSNs, Luhn-valid card runs) and will miss others and occasionally hit a non-PII string.
- No toxicity or content model runs locally. Hate, harassment and similar content pass the local demo untouched; only the cloud guardrail filters them.
- The rate limit counts in Redis, so it is shared by every API replica rather than per replica; it is a fixed one-minute window keyed by minute, which permits up to twice the limit across a minute boundary. On a Redis failure it allows the request and logs a warning: availability over strictness for an authenticated read API.
- Bedrock Guardrails were never exercised live in this repo. The Terraform validates and the Python parses a stubbed `apply_guardrail` response; the real filter strengths, the topic definition's recall and the blocked-message wording are unmeasured.
- `uncited` and `injection_suspected` are flags, not blocks. The UI and the audit row carry them; nothing downstream acts on them yet.
